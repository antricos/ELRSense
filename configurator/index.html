ELRSense Configurator

Board: ESP32-C3 Zero. Add the sensors you're using -- mapping each to a pin where applicable; download a single, self-contained .ino ready to open in Arduino IDE and flash.

View ESP32-C3 Zero pinout diagram

Hall/thermistor/voltage-divider/GPS sensors each get their own pin picker. GPS, INA226, and BMP280 are capped at one "+ Add" -- their CRSF frame type has no way to tell multiple readings apart.
